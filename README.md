> **UNO Classic** is a fast-paced, colorful card matching game designed with a **Ludo White & Colorful** aesthetic. Features Draw 2/4 cards, Reverse, Skip, Wild Color Swaps, and smart AI bot opponents!

---

## ✨ Features

- 🎨 **Ludo White & Colorful Theme**: Bright backdrop with vivid Red, Blue, Green, and Yellow card deck designs.
- 🃏 **Action Cards**: Full support for Skip, Reverse, Draw +2, Wild, and Wild Draw +4 cards.
- 🤖 **Smart AI Bots**: Practice against responsive computer opponents in fast-paced rounds.
- ⏸️ **In-Game Controls**: Pause/Resume controls, match restart, and clean game logging.

---

## 🛠️ Getting Started

```bash
# Clone the repository
git clone https://github.com/AlfiMaulanaA/UNO.git

# Navigate into the project
cd UNO

# Install dependencies
npm install

# Run development server
npm run dev
```
